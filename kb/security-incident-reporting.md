# Security Incident Reporting & Vulnerability Disclosure

## Reporting Security Issues
SupportFlow takes information security, account safety, and data privacy with utmost priority. If you detect or suspect any security vulnerability, data leakage, or unauthorized account access, report it immediately to our dedicated response team:
- **Email:** `security@supportflow.ai` (PGP key available upon request).
- **Emergency Hotline:** Available 24/7 in the Enterprise customer dashboard.

## Information to Include
When submitting a security vulnerability report, please provide:
1. Detailed description of the suspected vulnerability or anomaly.
2. Step-by-step reproduction instructions or proof-of-concept payload.
3. Affected workspace IDs, API endpoints, or user email addresses.
4. Any relevant HTTP request and response logs.

## Immediate Containment Actions
If you suspect an active credential compromise or unauthorized access to your workspace:
1. Immediately navigate to **Settings > Security > Active Sessions** and click **Revoke All Sessions**.
2. Rotate your API keys in **Settings > API Tokens**.
3. Reset your account password and generate new 2FA recovery codes.
4. Notify our security team so we can lock access logs and investigate potential data exposure.
