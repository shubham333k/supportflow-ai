# Pricing Plans & Feature Matrix

## Subscription Tiers
SupportFlow offers three distinct pricing plans suited for companies of different sizes:

### Starter Plan ($29/month)
- Designed for small teams and solo developers.
- Includes up to 3 user seats and 1,000 processed tickets per month.
- Basic email channel integration.
- Community forum support and standard 48-hour response SLA.
- Standard API access (60 requests per minute).

### Pro Plan ($99/month)
- Designed for scaling B2B businesses.
- Includes up to 10 user seats and 10,000 processed tickets per month.
- Email, Webhook, and Slack channel integrations.
- HubSpot CRM integration with 2-way sync.
- 4-hour priority support SLA during business hours.
- High-throughput API access (300 requests per minute).

### Enterprise Plan ($499/month)
- Tailored for large organizations and mission-critical workflows.
- Unlimited user seats and custom ticket volume allocations.
- Dedicated Customer Success Manager and 24/7 critical coverage.
- Custom SSO (Okta, Azure AD, SAML 2.0) and custom data retention policies.
- 1-hour immediate response SLA for high-priority incidents.
- Ultra-high throughput API access (1,200 requests per minute).
